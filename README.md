# OpenRouter Model Monitor

Скрипт следит за каталогом моделей [OpenRouter](https://openrouter.ai/models) и отправляет в Telegram-группы:

- 🆕 **все новые модели** → группа «новые»;
- 🆓 **бесплатные модели** (новые или ставшие бесплатными) → группа «бесплатные».

В сообщении: провайдер, полное название, ID модели, размер контекста, макс. ответ, модальность, цена за 1M токенов, дата появления в каталоге, ссылка.

## Установка

```bash
cd openrouter-model-monitor
npm install
cp .env.example .env
```

## Настройка `.env`

1. **Создай бота**: напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен в `TELEGRAM_BOT_TOKEN`.
2. **Добавь бота в группы** (нужны права на отправку сообщений).
3. **Узнай ID групп**: добавь в группу [@RawDataBot](https://t.me/RawDataBot) (или перешли любое сообщение бота в [@userinfobot](https://t.me/userinfobot)) — он покажет `chat_id`. Для групп ID отрицательный, вида `-100xxxxxxxxxx`. Впиши в `TELEGRAM_NEW_MODELS_CHAT_ID` и `TELEGRAM_FREE_MODELS_CHAT_ID` (можно одинаковые).
4. `OPENROUTER_API_KEY` — необязателен (эндпоинт публичный), но с ключом лимиты щедрее: https://openrouter.ai/keys

## Запуск

```bash
# разовая проверка + печать в консоль (без отправки, токен не нужен)
npm run check:dry

# разовая проверка с отправкой в Telegram
npm run check

# постоянный демон по расписанию (CRON_SCHEDULE, по умолчанию каждые 30 минут)
npm start
```

**Первый запуск — baseline:** кэш наполняется текущим каталогом без рассылки (иначе было бы 400+ сообщений). Дальше бот шлёт только изменения.

## Как это работает

- Раз в `CRON_SCHEDULE` забирается `https://openrouter.ai/api/v1/models`.
- Список сравнивается с JSON-кэшем (`cache/models.json`):
  - неизвестный ID → событие «новая модель» (если цена 0 — ещё и «бесплатная»);
  - известная модель с нулевой ценой, ранее платная → «стала бесплатной».
- События уходят в соответствующие группы, не более `MAX_MESSAGES_PER_GROUP` за прогон.
- Записи, не встречавшиеся 30 дней, удаляются из кэша.

## Держать запущенным (Windows)

Проще всего — окно терминала с `npm start`, либо автозапуск через `nssm`/планировщик задач, либо развёртывание на VPS с `pm2`:

```bash
npm i -g pm2
pm2 start src/index.js --name or-monitor
pm2 save
```
