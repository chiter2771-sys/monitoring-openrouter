# OpenRouter Model Monitor

Скрипт следит за каталогом моделей [OpenRouter](https://openrouter.ai/models) и отправляет в Telegram:

- 🆕 **все новые модели** → группа «новые»;
- 🆓 **бесплатные модели** (новые или ставшие бесплатными) → группа «бесплатные».

В ЛС бота доступны команды для ручного запроса информации о моделях.

## Установка

```bash
cd "Мониторинг OpenRouter"
npm install
cp .env.example .env
```

## Настройка `.env`

1. **Создай бота**: напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен в `TELEGRAM_BOT_TOKEN`.
2. **Добавь бота в группы** (нужны права на отправку сообщений, лучше сделать админом).
3. **Узнай ID групп**: добавь в группу [@RawDataBot](https://t.me/RawDataBot) — он покажет `chat_id`. Для групп ID отрицательный, вида `-100xxxxxxxxxx`. Впиши в `TELEGRAM_NEW_MODELS_CHAT_ID` и `TELEGRAM_FREE_MODELS_CHAT_ID` (можно одинаковые).
4. `OPENROUTER_API_KEY` — необязателен (эндпоинт публичный), но с ключом лимиты щедрее: https://openrouter.ai/keys

## Запуск

```bash
# тестовое сообщение в группу (проверка что бот пишет)
npm run test

# разовая проверка + отправка в группу
npm run check

# разовая проверка без отправки (только консоль)
npm run check:dry

# постоянный демон: мониторинг + команды в ЛС
npm start
```

**Первый запуск — baseline:** кэш наполняется текущим каталогом без рассылки. Дальше бот шлёт только изменения.

## Команды в ЛС (личные сообщения боту)

Напиши боту в Telegram (ЛС, не в группу):

| Команда | Описание |
|---|---|
| `/start` | Приветствие + список команд |
| `/free` | Список бесплатных моделей |
| `/paid` | Список платных моделей |
| `/all` | Список всех моделей |
| `/search <имя>` | Поиск по названию или провайдеру |
| `/test` | Тестовое сообщение в реальном формате |

Каждая команда показывает: название, провайдер, контекст, цену за 1M токенов, ссылку на openrouter.ai.

## Как это работает

- **Группы**: раз в `CRON_SCHEDULE` забирается `https://openrouter.ai/api/v1/models`. Список сравнивается с JSON-кэшем (`cache/models.json`):
  - неизвестный ID → событие «новая модель» (если цена 0 — ещё и «бесплатная»);
  - известная модель с нулевой ценой, ранее платная → «стала бесплатной».
- **ЛС**: polling через `getUpdates` — бот проверяет новые сообщения каждую секунду.
- События уходят в соответствующие группы, не более `MAX_MESSAGES_PER_GROUP` за прогон.
- Записи, не встречавшиеся 30 дней, удаляются из кэша.

## Держать запущенным (Windows)

Проще всего — окно терминала с `npm start`, либо автозапуск через `nssm`/планировщик задач, либо развёртывание на VPS с `pm2`:

```bash
npm i -g pm2
pm2 start src/index.js --name or-monitor
pm2 save
```
